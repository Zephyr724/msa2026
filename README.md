# Kiwimpact — Community eco quests across New Zealand

**Status: planning and specification**

Kiwimpact is an Auckland-first gamified community environmental participation
platform for Aotearoa New Zealand. This repository is in the planning phase.
No application code has been scaffolded.

## Current state

- Accepted planning baseline: [`specs/Kiwimpact_Final_Planning_Baseline_v1.0.md`](specs/Kiwimpact_Final_Planning_Baseline_v1.0.md)
- Project profile: [`specs/00-project-profile.md`](specs/00-project-profile.md)
- Planned stack: React + TypeScript + Vite (frontend), C# .NET 10+ + ASP.NET Core (backend), PostgreSQL
- Agent steering rules: [`.clinerules/`](.clinerules/)
- Implementation status: [PROJECT_STATUS.md](PROJECT_STATUS.md)

## `/specs`

The `/specs` directory contains the accepted intended product and architecture
specifications. Source code, migrations, lockfiles, and tests will prove the
currently implemented state once scaffolding begins.

## Legacy materials

The `docs/archive/legacy-task-api/` directory contains superseded
Node.js/Express/SQLite Task API artifacts. These files are inactive and are
not part of the Kiwimpact project.
